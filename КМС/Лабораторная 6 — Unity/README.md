# Лабораторная работа 6

Программное создание объектов и обработка щелчков мышью в Unity.
Версия редактора: 6000.6.4f1.

## Запуск

Добавить папку UnityLab6 в Unity Hub. В окне Project открыть Assets/Lab6/Scenes, выбрать нужную сцену двойным щелчком и нажать Play. Для ввода с клавиатуры щёлкнуть внутри окна Game.

## Сцены

«кубики»: Q создаёт куб над плоскостью. W наклоняет плоскость, повторное нажатие возвращает её в горизонтальное положение.

«Генерация объектов»: Q создаёт куб, Space — сферу из префаба Sphere. W наклоняет плоскость.

«Щелчки мышью»: щелчок левой кнопкой по кубу меняет его цвет и прикладывает силу в точке нажатия. На сцене расположена стена из 4 рядов по 8 кубов и отдельный куб для проверки. Все кубы — сохранённые экземпляры префаба ClickableCube.

Для восстановления сцены остановить Play и запустить его снова. Сцены переключаются вручную через окно Project.

## Объекты и код

Камеры, освещение, плоскости, EventSystem и стена сохранены в сценах. Их можно просматривать и перемещать в Hierarchy до запуска Play. Скриптов сборки сцены нет.

Assets/Scripts/PlaneGenerator.cs расположен на Plane. Он создаёт только кубики по Q и сферы по Space и наклоняет плоскость по W. Rigidbody плоскости настроен в Inspector: Use Gravity выключен, Is Kinematic включён. Префаб сферы назначен в поле Prefab1.

Assets/Scripts/ClickReaction.cs расположен на префабе куба. Реализует IPointerClickHandler: выбирает случайный RGB-цвет и вызывает AddForceAtPosition. На камере сцены щелчков есть PhysicsRaycaster, а на EventSystem — StandaloneInputModule.

Используется встроенный Input Manager. В проекте нет интерфейса подсказок, автоматического переключения сцен и удаления упавших объектов.
