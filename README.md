# Лабораторные работы · 3 курс БГТУ

Учебный репозиторий с лабораторными работами по базам данных, серверной разработке, операционным системам и компьютерной графике.

| Предмет | Что изучаем |
|---|---|
| **Базы данных** | Oracle DB: проектирование баз данных, SQL и администрирование. |
| **Компьютерные мультимедийные системы** | 3D-моделирование и разработка на Unity. |
| **Операционные системы** | Устройство ОС и ядра, работа с терминалом и виртуальными машинами. |
| **Программирование серверных кроссплатформенных приложений** | Разработка серверных приложений на Node.js. |
| **Программирование серверных приложений** | Компьютерные сети: модель OSI, передача данных, протоколы, взаимодействие серверов и сетевые утилиты. |
| **Системное программирование** | Динамические библиотеки DLL и SO: создание, подключение и загрузка во время выполнения. |
| **Технологии программирования в Интернет** | Разработка серверов и Web API на ASP.NET Core, работа с nginx. |

Работы добавляются по мере прохождения курсов. Лабораторные по программированию серверных приложений выполняются в другой ОС и могут отсутствовать в репозитории.
