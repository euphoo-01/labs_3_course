# Mission: Защита лабораторных работ по NGINX и ASP.NET Core Logging

## Why
Подготовиться к защите совмещённых лабораторных работ: уверенно объяснить теорию NGINX из первой работы и показать, как устроен и работает Web API второй работы.

## Success looks like
- Своими словами объяснить назначение, архитектуру и базовую конфигурацию NGINX.
- Проследить полный путь HTTP-запроса через middleware, контроллер, реестр и `System.Threading.Channels`.
- Объяснить уровни, категории, провайдеры и фильтрацию логов в ASP.NET Core.
- Без подсказки провести демонстрацию API и объяснить каждый полученный HTTP-статус.
- Ответить на типичные вопросы преподавателя и назвать ограничения текущей реализации.

## Constraints
- Основой служат выданные методички, лекции и уже готовый проект в `L1-2`.
- Подготовка ориентирована на устную защиту, а не на промышленную доработку приложения.

## Out of scope
- Полноценное развёртывание NGINX на отдельном сервере.
- Перевод лабораторного приложения на внешнюю брокерскую систему или базу данных.
