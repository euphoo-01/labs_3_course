# m0603 — отправка строки на фиксированный email

Пакет для лабораторной работы №06 по ПСКП. Экспортирует **одну функцию** `send(message)`.

```js
const { send } = require('m0603');

send('Тестовое сообщение')
  .then(() => console.log('SMTP принял письмо'))
  .catch(console.error);
```

`message` — единственная строковая аргумент; функция возвращает `Promise`.

Адрес получателя сейчас фиксирован в исходном коде модуля и не передаётся в `send`.

Переменные окружения:

- `MAIL_DRY_RUN=1` — вывод письма в консоль без отправки;
- `MAIL_DEV_HOST=127.0.0.1` и `MAIL_DEV_PORT=1025` — отправка в локальный SMTP-сервер вместо внешней доставки.

Успешный ответ SMTP означает **приём к обработке**, а не гарантированную доставку в почтовый ящик.
